On slow software

By Rich Text on March 8, 2022

Software that is slow to write is often fast to read.

There is a kind of patience in a program that does one thing per line, in order, with no cleverness at all. It is not fashionable. It is very easy to debug.

  • it fits in your head
  • it fits on a screen
  • it fits in a talk

That is the whole argument.
