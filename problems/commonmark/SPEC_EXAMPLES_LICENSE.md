# Licence of the CommonMark spec examples

`spec_examples.json` holds the examples of the CommonMark Spec 0.31.2
(<https://spec.commonmark.org/0.31.2/>), extracted from its `spec.txt` by
`gen_tests.py --extract`: each example's Markdown and HTML, unchanged.
The tests built from them (`tests/029_spec_*` to `tests/056_spec_*`) group the
examples into test cases.

Attribution-ShareAlike 4.0 International licence (CC BY-SA 4.0),
reproduced in `LICENSE-CC-BY-SA-4.0.txt`
(<https://creativecommons.org/licenses/by-sa/4.0/>). `spec_examples.json`
and those tests are under that licence, not this repository's MIT licence.
