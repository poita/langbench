# Third-party data in these tests

- `064_valid_*` to `271_valid_*` and `272_invalid_*` to `772_invalid_*`: the
  TOML 1.0.0 files of the official TOML test suite
  (<https://github.com/toml-lang/toml-test>), unmodified, MIT
  (`LICENSE-toml-test.txt`).
- `813_real_*` to `825_real_*`: configuration and lock files of serde,
  ripgrep, tokio, cargo, black, ruff, pydantic and uv, unmodified, each under
  its project's MIT licence (`LICENSE-black-MIT.txt`, `LICENSE-cargo-MIT.txt`,
  `LICENSE-pydantic-MIT.txt`, `LICENSE-ripgrep-MIT.txt`, `LICENSE-ruff-MIT.txt`,
  `LICENSE-serde-MIT.txt`, `LICENSE-tokio-MIT.txt`, `LICENSE-uv-MIT.txt`).

Every other test is written or generated by this project.
