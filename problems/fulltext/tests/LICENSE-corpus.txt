Corpus provenance and licence
=============================

Project Gutenberg texts
-----------------------

The 36 `*.txt` files in this directory are the bodies of public-domain works
obtained from Project Gutenberg (https://www.gutenberg.org/).  `make_corpus.py`
downloaded each one, kept only the text between the `*** START OF THE PROJECT
GUTENBERG EBOOK ***` and `*** END OF THE PROJECT GUTENBERG EBOOK ***` markers,
and then removed every line mentioning Project Gutenberg.  The files therefore
contain none of Project Gutenberg's header, footer, licence or trademark text,
and carry no Project Gutenberg licence obligations.

The underlying works are in the public domain in the United States and in most
other jurisdictions; every author and translator died before 1950.

Porter stemmer test vocabulary
------------------------------

  porter/voc.txt     23531 words
  porter/output.txt  their stems

These are Martin Porter's own test files for the 1980 stemming algorithm,
from https://tartarus.org/martin/PorterStemmer/.  Porter placed the algorithm
and all of its accompanying material in the public domain: "the software is
completely free for any purpose" (https://tartarus.org/martin/PorterStemmer/).
gen_tests.py uses them purely as an oracle for the reference stemmer, and
derives the documents of tests/017_porter_vocabulary from voc.txt.
