# Third-party data in these tests

- `017_porter_vocabulary`: Martin Porter's stemmer test vocabulary
  (<https://tartarus.org/martin/PorterStemmer/>), free for any purpose.
- `030_books_whole`, `031_book_chapters`, `032_library_chunks`: public-domain
  books from Project Gutenberg, with Project Gutenberg's header, footer and
  licence removed.

`LICENSE-corpus.txt` lists every book and the vocabulary's terms. Every other
test is written or generated by this project.
