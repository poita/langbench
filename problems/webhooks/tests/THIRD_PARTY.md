# Third-party data in these tests

- `003_spec_vector`: the published test vector of the Standard Webhooks
  specification (<https://github.com/standard-webhooks/standard-webhooks>),
  Apache-2.0 (`LICENSE-standard-webhooks.txt`).
- `029_nist_*`, `030_nist_*`: NIST CAVP SHA-256 test vectors, a work of the
  U.S. federal government (public domain in the United States).
- `031_github_*` to `034_github_*`: GitHub webhook payload examples from
  <https://github.com/octokit/webhooks>, MIT (`LICENSE-octokit-webhooks.txt`).

Every other test is written or generated by this project.
