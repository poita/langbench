# Third-party data in these tests

- `028_chinook_*` to `031_chinook_*`: the Chinook sample database
  (<https://github.com/lerocha/chinook-database>), MIT
  (`LICENSE-chinook.md`). Its customers and employees are fictional.
- `032_airports_*` to `034_us_airports_*`: OurAirports open data
  (<https://ourairports.com/data/>), released to the public domain
  (`LICENSE-ourairports.txt`).

Every other database is generated by this project.
