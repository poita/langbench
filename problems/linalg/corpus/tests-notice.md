# Third-party data in these tests

Tests `027_ss_*` to `041_ss_*` use matrices of the SuiteSparse Matrix
Collection, group HB, under CC BY 4.0 (`LICENSE-CC-BY-4.0.txt`), as described
in `CORPUS_LICENSE`. An unchanged matrix keeps its original header; an adapted
one carries a comment line naming the source matrix and stating the change.
Every other test is generated by this project.
