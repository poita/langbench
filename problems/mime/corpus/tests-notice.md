# Third-party data in these tests

- `028_mime4j_a` to `030_mime4j_c`: test messages from Apache James mime4j
  (<https://github.com/apache/james-mime4j>). Those from its `testmsgs/` are
  under the Apache License 2.0; those from `mimetools-testmsgs/`, created by
  Eryq and ZeeGee Software Inc for the MIME-tools Perl5 toolkit, are under the
  Artistic License. Both are in `LICENSE-mime4j.txt`; upstream's notice is in
  `NOTICE-mime4j.txt`.
- `031_mailgem_a` to `033_mailgem_c`: test fixtures of the Ruby `mail` gem
  (<https://github.com/mikel/mail>), MIT, `LICENSE-mailgem.txt`.

The messages are unmodified apart from CRLF line endings converted to LF.
Every other test is written or generated by this project.
